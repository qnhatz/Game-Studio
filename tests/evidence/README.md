# Test Evidence

Manual test sign-offs and screenshot records for Visual/Feel and UI story types.

## Naming convention

`[date]-[story-id]-[system]-[verdict].md`

Example: `2026-05-15-story-003-main-menu-approved.md`

## Required fields in each evidence doc

- Story ID and title
- Story type (Visual/Feel / UI)
- Acceptance criteria checked
- Verdict: APPROVED / APPROVED WITH CONDITIONS / REJECTED
- Sign-off: lead programmer or art director (per story type)
- Screenshots or recording link (if applicable)
